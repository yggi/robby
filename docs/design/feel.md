# The feel — what the player sees, hears and touches

Everything here is load-bearing, because the player cannot read. Meaning arrives
as motion, colour and sound or it does not arrive at all, so these are not
finishing decisions — they are the interface.

## The shape of it

Two rules run through every page here.

**Sameness is information.** The console never changes, so it is furniture; the
world changes completely, so it is a place. A bonk looks the same every time
because it is telling you something; a celebration varies because it is not.

**A colour means one thing, everywhere.** Orange is power, teal is go, and the
four direction colours run from the tray token through the filled slot to the
line drawn on the board. A child matching a colour under their thumb to a colour
on the map is the game working. Spending one of those colours on decoration
breaks it silently.
